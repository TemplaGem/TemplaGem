    Від шаблону до готового запиту за три дії

    TemplaGem вбудовується безпосередньо в Quill-редактор сторінки gemini.google.com і бере на себе всю рутину з форматуванням.

    01 / Focus Click

    Миттєвий доступ біля поля вводу

    Щойно ви ставите курсор у поле чату Gemini, над ним з'являється легке вікно зі списком ваших шаблонів, пошуком та фільтрацією за тегами.

    #навчання   #код   #email
    ▸ Конспект матеріалу
      Code Review & Refactor
    02 / Fill Tab

    Підсвічування {{змінних}} та навігація

    Кожен параметр у подвійних фігурних дужках перетворюється на інтерактивний токен. Почніть друкувати, щоб замінити значення, і натискайте Tab для переходу далі.

    Зроби конспект за темою: {{тема}} для рівня {{рівень}}
    03 / Send Enter

    Автоматичне очищення дужок при відправці

    Навіть якщо ви залишили якусь змінну за замовчуванням, під час натискання Enter або кнопки відправки розширення прибере службові дужки {{ }}.

    {{TypeScript}} → TypeScript

    Спроектовано спеціально під екосистему Google Gemini

    Жодних важких фреймворків поверх сторінки чи конфліктів із політиками безпеки браузера.

    40+ тематичних іконок у 5 категоріях та 6 режимів сортування

    Призначайте кожному шаблону власну кольорову іконку (AI & Tech, Writing & Learning, Productivity, Media & Fun) та впорядковуйте список за датою створення, оновлення або алфавітом.

    ✦ Sparkles · AI & Tech </> Code · Dev ✎ Writing & Study ⚡ Productivity

    Хмарна синхронізація + миттєвий кеш

    Шаблони синхронізуються з вашим обліковим записом через захищений REST API (JWT + автооновлення токенів) і дублюються в локальному сховищі браузера для миттєвого відкриття.

    TanStack Query → Background SW → chrome.storage.local

    Сумісність із Trusted Types та Quill

    Сторінка gemini.google.com блокує звичайний innerHTML через політику Trusted Types. TemplaGem використовує DOM TreeWalker та нативні діапазони Range, не ламаючи внутрішній стан редактора.

    Технічний стек проєкту

    • Framework
      Plasmo MV3 + React 18
    • State & Validation
      TanStack Query v5 + Zod v4
    • Theme Engine
      Auto / Light / Dark Sync
    • Quality Assurance
      Vitest (>85% cov) + Playwright

    Встановлення за 30 секунд

    Оберіть зручний спосіб: завантажте готовий архів із GitHub Releases або зберіть розширення локально з вихідного коду.

    Крок 1

    Завантажте архів збірки

    Перейдіть у розділ Releases на GitHub, завантажте файл chrome-mv3-prod.zip та розпакуйте його у зручну папку.

    Відкрити GitHub Releases
    Крок 2

    Увімкніть Режим розробника

    Відкрийте сторінку керування розширеннями у вашому браузері та активуйте перемикач Developer mode у верхньому кутку.

    chrome://extensions
    Крок 3

    Завантажте розпаковане розширення

    Натисніть «Load unpacked» (Завантажити розпаковане) і виберіть розпаковану папку chrome-mv3-prod. Готово!

    Крок 1

    Клонуйте репозиторій

    Склонуйте проєкт TemplaGem та встановіть залежності через pnpm.

    pnpm install
    Крок 2

    Зберіть production-бандл

    Виконайте команду збірки Plasmo. Готове розширення з'явиться в папці build/chrome-mv3-prod.

    pnpm build
    Крок 3

    Додайте в браузер

    На сторінці chrome://extensions натисніть «Load unpacked» та вкажіть шлях до build/chrome-mv3-prod.

    build/chrome-mv3-prod
